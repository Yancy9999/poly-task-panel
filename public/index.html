字体

          

            
            
            
全局字体：界面与终端统一跟随此处选择。终端是等宽栅格渲染，须用等宽字体；带中文字形的等宽字体（如等距更纱黑体）才能让中英文宽度一致。

          

          

            
            
          

          

            
            
仅部分区域跟随：终端 / 日志 / 文件编辑器 / Git diff / 任务工作台的选项、目标与 agent 输出；其余界面元素保持固定字号。

            
          

          

            
            
claude code #1 | preview 0123456789 | 中文示例 终端 █

          

        

        

          
命令

          
配置终端栏底部「/」按钮弹出的常用命令。每行一条，格式：命令|中文说明（说明可省略）；claude / codex / pi 独立配置。

          

            
            
            
          

          

            
            
            
          

          

            
            
            
          

        

        

          
常用文本

          
配置终端栏底部「常用文本」按钮弹出的文本条目。每行一条纯文本，点选后直接输入到当前终端（不回车，可继续编辑）；按会话类型分两份配置：Agent（claude / codex / pi）与命令行（cmd / Git Bash）。支持转义：\r 回车（末尾加 \r = 点击后直接提交）、\n 换行、\t Tab、\\ 字面反斜杠（路径如 C:\\repos\\test）。

          

            
            
          

          

            
            
          

        

        

          
文件

          
文件抽屉中不显示的目录/文件名黑名单。每行一条，精确匹配名称（如 .git、.svn、node_modules）；不影响其它点号开头文件（.gitignore / .env 等正常显示）。
